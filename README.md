

# 🛍️ E-Commerce React App

A modern **React E-commerce application** built with **React Router v6**.
This app provides users with a smooth shopping experience — including browsing products, viewing product details, managing their cart, and exploring categories like **Jewellery**, **Electronics**, **Men’s Clothing**, and **Women’s Clothing**.


## 🚀 Features

* 🏠 **Home Page:** Showcases featured products and categories.
* 🛒 **Shop Page:** Displays all available products.
* 💎 **Category Pages:** Separate sections for:

  * Jewellery
  * Electronics
  * Men’s Clothing
  * Women’s Clothing
* 🧾 **Product Details Page:** View detailed info for each product via dynamic routing (`/shop/:id`).
* 🛍️ **Cart Page:** Add or remove items and manage your shopping cart.
* 📞 **Contact Page:** Allows users to reach out with inquiries.
* 🔝 **ScrollToTop Component:** Smooth scrolling to top when navigating between pages.
* ⚙️ **Reusable Layout Component:** Common structure with header, footer, and main content area.


## 🧩 Tech Stack

| Category             | Technology                              |
| -------------------- | --------------------------------------- |
| **Frontend**         | React.js (Vite or CRA)                  |
| **Routing**          | React Router DOM v6                     |
| **Styling**          | Custom CSS                |
| **State Management** | React Hooks (useState, useEffect, etc.) |
| **Components**       | Reusable functional components          |
